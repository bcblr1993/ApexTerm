## 本轮修复

- 终端获得/失去焦点时显式激活/停用输入上下文，修复真实拼音输入的首字符漏发；真实拼音预编辑、取消、提交及恢复原输入法已通过。
- Vim 普通字符数据包误入历史；方向键的应用光标模式；光标刷新；视口尺寸与分屏重排。
- UTF-8 跨包中文；CJK/Emoji 双宽单元格；宽字边界删除、插入、擦除和缩小窗口。
- 背景色、斜体、下划线、删除线、反白；xterm 256 色色阶。
- 鼠标跟踪的按下、释放、拖动和滚轮；RIS 重置、控制字符串碎片、缩放后恢复光标。
- 实际渲染中的关键词高亮；⌘1…9 标签切换；⌘+/−/0 字号调整。
- OSC 目录提示跨包和百分号编码；IPv6 跳板机参数；SFTP 特殊字符文件名、连续空格和 macOS 文件修改时间。
- 移除终端/滚动层的异步绘制标记；光标或控制包不重复编辑历史文本。刷新排版完成后再安排下一帧，避免已到期的刷新任务连续占用主线程。
- 历史行数设置用于新终端并可调整现有缓冲；画面同步按完整 Unicode 行淘汰，避免超过配置上限。
- 同目录提示符合并为尾随刷新，目录真正变化仍立即同步，避免大量命令反复刷新 SFTP；提示符路径不跨行匹配，避免普通命令输出误改文件面板目录。
- 每个 SSH 客户端使用独立复用连接，避免关闭一个同主机标签时影响另一标签的 SFTP/监控。
- PTY 写入移到有序后台队列，循环处理部分写入；断开时避免重复关闭描述符。
- 混合中文/Emoji 时固定使用配置字体计算网格；实际 glyph advance 对齐单元格，避免 AppKit 回退字体令光标漂移。现有输出改变字号后重新计算字距与 ANSI 字体样式，回归先复现约 2 像素偏差、修复后通过。
- 合并 TextKit 文本更新；相同布局不重复取消尺寸通知，回到原尺寸时取消过期通知，新会话重新同步。
- SSH 子进程重置信号掩码与 SIGWINCH 默认处理，修复本地视口变化但远端 PTY 保留旧行列的问题。新增真实 Vim 连续三种尺寸的回传断言；修复前失败、修复后通过。真实文件面板展开/收起返回 23×84 / 34×84。

- 终端固定使用覆盖式滚动条，避免系统因输入设备切换滚动条样式而改变可视宽度、触发整份历史重新排版；满历史下的样式切换、滚动跟随和历史阅读回归通过。系统“始终显示滚动条”的样式偏好不再改变终端占位宽度。
