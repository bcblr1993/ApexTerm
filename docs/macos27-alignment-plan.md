# ApexTerm macOS 27 全面设计与性能对齐计划

范围：本轮交付可执行计划，不修改产品代码。实施目标是全界面原生化、主题可读、交互完整、性能有实测证据；完成计划不代表完成产品改造。

## 设计基准与边界

- 官方依据：Apple HIG、Adopting Liquid Glass、WWDC26 Modernize your AppKit app。
- https://developer.apple.com/design/human-interface-guidelines/
- https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass
- https://developer.apple.com/videos/play/wwdc2026/289/
- 优先采用系统窗口、工具栏、侧栏、列表、菜单、表单、弹窗与 SF Symbols；自定义玻璃只用于原生组件无法表达的交互区域。
- 终端和文件内容以清晰、稳定的表面呈现；导航和操作区域使用系统材质。圆角、焦点、选中、禁用、窗口非激活状态交由系统管理。
- 默认经典白色保持。现有 12 个配色全部保留；设计上明确窗口外观、强调色、终端色板的关系，避免自定义背景覆盖系统材质。提供跟随系统明暗模式，不静默丢弃用户配色偏好。
- macOS 27 专用 API 必须通过可用性检查；保持现有 macOS 14 最低支持范围。终端引擎继续使用 AppKit，不因外观改造整体替换。

## 现状依据

- 当前 Git 工作区检查无修改。
- 主窗口已采用 NavigationSplitView，但 WorkspaceView 仍有自绘操作条、标签背景；窗口标题、会话信息和标签分成多层。
- 终端已有增量刷新与合并刷新机制。应先测量，再优化，避免重写已经有效的路径。
- 当前截图中侧栏分组背景较重，工具栏按钮偏小；文件区叠加路径、操作、过滤和表头；监控占用较多顶部空间。

| 阶段 | 工作 | 交付与验收证据 |

| 0 基线与规范 | 用最新 Xcode/SDK 核查可用 API；记录现有窗口和页面截图、Instruments CPU/内存/帧时间；固定演示数据、设备、构建配置和负载 | 页面状态矩阵、基线报告、统一字体/间距/图标规范；所有性能比较使用相同条件 |
| 1 设计预览 | 制作主窗口、文件面板、监控弹出层、设置和会话编辑的真实尺寸预览；验证浅/深主题及窄窗口；确认截图幽灵是否属于产品装饰 | 设计预览与组件规范。预览通过后进入实现；主工作区装饰不得遮挡内容或拦截输入 |
| 2 窗口与导航 | 会话标题与主要操作进入原生 toolbar；只保留一行标签；系统侧栏、分组、搜索、选中态；原生分隔与拖拽边界；窄窗口操作自动收纳 | 标题栏、侧栏、标签、单/双分屏和全屏前后对照；无重叠、截断、重复状态与额外空白条 |
| 3 终端与会话交互 | 保留增量渲染；统一焦点、光标、选区、查找栏、URL 菜单、广播、重连与连接中状态；断线提示与当前分屏关联；检查鼠标命中及键盘路由 | 真实 SSH 输入、IME、复制/粘贴、查找、分屏、切换、缩放、断线重连录像或步骤证据；状态一致 |
| 4 SFTP 与编辑 | 紧凑路径栏、常用操作组和更多菜单；原生表格列、排序、选择、右键；过滤按需显隐；上传下载记录稳定展示；统一编辑器与未保存处理 | 点击/拖拽双向传输内容哈希、远程结果与可见目录一致；新建/重命名/删除、取消、失败、重复文件完整验收 |
| 5 监控与其余页面 | 监控默认摘要，详情分组，按可见性更新图表；设置、导入、会话编辑、关于、更新、快捷键、传输中心统一原生表单与 sheet | 各页面正常/空/加载/失败/禁用/成功/取消状态截图，监控过期和断线状态明确，不用颜色单独传递状态 |
| 6 主题与无障碍 | 12 主题覆盖所有组件；增强对比度、减少透明度/动态效果、VoiceOver、全键盘访问；保存窗口、布局、主题和目录状态 | 自动对比度测试 + 真实系统外观检查；键盘完整流程；窗口恢复不等同于自动重连生产 SSH |
| 7 性能收敛 | Instruments 找热点；缩小 SwiftUI 观察范围；指标更新不重建终端和文件列表；索引/缓存避免逐字符重复转换；关闭不可见视图的高频刷新；任务生命周期可取消 | 同机同构建的前后性能报告；高负载、多会话、长时间运行和快速关闭/重开无泄漏、卡顿或重复后台任务 |
| 8 完整验收与交付 | 全量测试、真实 Tart VM、8 项优化构建基准、Swift 6 零警告、CI；实际 App 窗口验收，不能只依赖测试 HostingWindow | 每条需求关联截图/日志/数据；实现阶段先交付可安装候选版。正式发布在明确授权后执行签名、公证、安装、更新、公开下载校验和回滚验证 |

## 性能预算

以下 UI 数值是项目拟定的验收目标，不是 Apple 强制规范；阶段 0 固定设备与场景后校准并记录，不以无证据的数字宣称完成。

- 交互：规定滚动、分屏拖拽、标签切换场景，60 Hz 屏幕帧时间 P95 ≤ 16.7 ms；120 Hz 设备争取 ≤ 8.3 ms。分别测量，不承诺所有设备持续 120 FPS。
- 输入：真实 PTY 回显与 IME 单独测量 P50/P95；现有每键微秒基准只表示内部代码路径，不能替代端到端回显延迟。
- 空闲：定义前台无输出、无传输、监控开/关四类场景；监控关闭时 CPU 目标 ≤ 单核 1%，通过 60 秒以上采样验证；隐藏窗口减少更新，SSH/传输业务仍继续。
- 内存：定义历史容量、单/多会话、文件列表和图表负载；受控基准 RSS ≤ 250 MB。真实工作负载单独报告，不把基准上限套用到任意数量会话。
- 稳定性：30 分钟持续输出、监控和传输组合测试；预热后无持续无界内存增长、丢输入、错误选区或丢失传输记录。
- 优化构建沿用 SOP：RingBuffer ≥ 50,000 行/秒且 ≥ 5 MB/秒；ANSI ≥ 150,000 spans/秒；并发写入 ≥ 1,000,000 writes/秒；指标 ≥ 8,000 次/秒；SSH 配置 ≥ 80,000 hosts/秒；SFTP 调度 ≥ 800 tasks/秒；内部键入基准 ≤ 15 μs。
- 任何视觉变化导致性能回退，都记录原因和测量；优先减少自绘、重复模糊层、动画和重算，保留功能与可读性。

## 覆盖矩阵与完成标准

- 页面：欢迎/工作台、侧栏、标签、单/双分屏、终端查找/广播/重连、SFTP、编辑器、传输抽屉、监控详情、设置、导入、会话编辑、关于、更新、快捷键、确认与错误弹窗。
- 外观：12 主题；浅/深系统外观；窗口激活/非激活；增强对比度；减少透明度与动态效果。组合采用代表性覆盖加全主题关键页面验收，不宣称未经执行的完整组合测试。
- 尺寸：当前最小窗口、常用桌面尺寸、全屏、不同分屏比例；截图按逻辑尺寸和显示缩放记录。
- 数据：无会话、单/多会话、长会话名、长路径、大目录、长日志、长错误、过期指标及网络中断。
- 完成要求：每项计划均有实现或明确不适用的依据；每个关键状态有实际窗口证据；原有 SSH/SFTP 功能无回退；主题和无障碍可读；性能预算有同条件实测；候选包验签安装启动通过。
- 发布完成另要求：版本/构建号/CHANGELOG/Tag 对齐；CI、VM、签名、公证、下载校验、更新发现与旧版回滚逐项通过。

## 推荐推进方式

先进行阶段 0–1，交付“主窗口设计预览 + 性能基线 + 全页状态矩阵”；确认视觉方向后依次实现阶段 2–7，最后用阶段 8 完整收尾。每阶段报告实际变化、证据和遗留项，不把单页漂亮或单元测试绿色等同于全面对齐。
