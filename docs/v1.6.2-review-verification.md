# v1.6.2 审核修复验证

Apple 于 2026-10-08 对 1.6.0（2026100203）提出两项问题：主窗口关闭后无法从菜单恢复，以及用户文档保存于隐藏沙盒目录。

## 修复

- 保留 WindowGroup，让关闭最后一个窗口后应用和菜单继续运行；增加“窗口 → 显示主窗口”和 ⇧⌘0。以现有 frameAutosaveName 查找工作区，避免 SwiftUI 重写窗口 identifier 后重复创建。
- 商店单文件下载使用 NSSavePanel；目录和批量下载使用 NSOpenPanel，明确选择可访问的保存位置。取消不创建传输任务。
- 新保存目标建立不覆盖内容的文件，再生成文件书签；传输 helper 保持该授权至完成。拒绝符号链接目标。
